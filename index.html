Personal desktop application

A local production companion for original stories.

NovaTales Lab helps its operator prepare fictional video stories, assemble manually generated clips, and manage the operator’s connected YouTube channel.

This website provides information about the application and its data practices. The desktop application runs on the operator’s own Windows computer.

How the workflow works

  1. Prepare a story. Local software prepares a storyboard, generation prompts and editorial metadata.
  2. Create the footage. The operator manually generates clips with a chosen video service and delivers the files through a locally synchronized folder.
  3. Assemble and review. The desktop application imports copies, preserves source files, assembles clips and performs technical checks. The operator receives a preview, proposed metadata and a thumbnail through their configured Telegram bot.
  4. Authorize a private upload. A specific approval of the reviewed file and metadata allows the application to upload that version as a private YouTube video. Public publication requires a separate decision.

Google account connection

The operator connects their own YouTube channel using Google’s desktop OAuth consent flow. Permissions support channel identification, channel statistics, analytics and authorized private video uploads.

Google consent and the final approval of an individual upload are separate steps.

Operator-controlled software

NovaTales Lab is currently a personal-use application for its channel operator. This informational website does not provide account registration, a Google sign-in flow, a video-upload form or access to the operator’s local application.

Support

For support or a question about data handled by NovaTales Lab, use the support email displayed on the Google consent screen for this application.
